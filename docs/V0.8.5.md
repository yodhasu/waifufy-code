# Waifufy Code 0.8.5: mods can start a session

0.8.5 lets a mod take over the chat: start a fresh session in a folder, in a permission mode, with a first message, and interrupt it later. It exists for REM (Running Every Midnight), the nightly fixing run, but any mod that declares the permission can use it.

## Mod capabilities

- **`session.start`** `{ cwd, mode?, text? }`: ends the session that is open (even mid-turn), starts a new one in `cwd`, applies `mode` (`default`, `acceptEdits`, `plan`, `auto`, `bypassPermissions`) and says `text` as the first message. Returns `{ epoch }`. A missing or untrusted folder is refused with the reason. Every window switches to the new session (`session_started`), the phone included.
- **`session.interrupt`**: stops the running turn, like the Stop button.
- Each needs its own permission in `mod.json` (`"session.start"`, `"session.interrupt"`). A backend calls them with an `app.call` request, a panel with `waifufy.app(...)`.

## The REM mod (plugins/rem)

Installed per user in `%APPDATA%/waifufy-code/mods/rem`. Each night at 21:00 it starts a session in your work folder in auto mode with the night brief, forwards every new ticket labelled `rem` from the ticket board, says "wrap up" at 06:00 and interrupts at 06:30. Times, folder, brief file and label are mod settings. Folder and brief start empty: set them after installing, and keep the brief in the mod's folder or add an `fs.read:` permission for its folder to `mod.json`. If the app is opened during the night, it starts then; outside the night it does nothing.
